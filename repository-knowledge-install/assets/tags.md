# Реестр тегов

Каждая запись содержит backticked tag, назначение и поле `owner` с относительной
Markdown-ссылкой на существующую страницу-владельца. Добавляйте тег только
тогда, когда одно устойчивое понятие требуется связать и с управляемой
документацией, и с кодом.
